# Development Logs

One log per phase: `phase-<N>-<slug>.md`. Template and rules in `../POLICY.md §1`.

**A phase is not complete without its log.** The human verifies each phase by
hand and may resume with a different agent or model days later — this directory
is the only continuity that survives.

- `phase-0-scaffold.md`, `phase-1-api-client.md`, … one per phase
- `DECISIONS.md` — running one-line log of cross-phase decisions (append only)

If you are starting cold: read every log here, oldest first, before writing code.
